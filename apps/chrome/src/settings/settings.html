VoiceCoder Settings

Model provider

VoiceCoder understands open-ended requests and writes code with your own key (BYOK). Keys are stored in this extension's local storage. Only the background worker reads them, and it sends them only to the provider's API.

Model

Leave empty for the provider default (claude-opus-5-5 or gpt-4.1).

Speech

Recognition language and listening mode. Hindi and Telugu depend on Chrome's speech service.
